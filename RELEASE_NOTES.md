## Porch Light Android v1.0.0

Initial release of Porch Light Android app.

### Features
- 📱 WebView-based Android app
- 🔐 Google OAuth integration
- 📅 Google Calendar access (read-only)
- 🌙 Material Dark Theme support
- ⬅️ Native Android back button support

### Installation

1. Download the `porch-light-v1.0.0.apk` file from this release
2. Transfer to your Android phone (or download directly on phone)
3. Open the APK file on your phone
4. Tap "Install"
5. Grant permissions when prompted
6. Launch and sign in with Google!

### Requirements
- Android 7.0+ (API 24+)
- Internet connection
- Google account for OAuth

### Troubleshooting

If installation is blocked:
- Go to Settings → Security
- Enable "Unknown Sources" or "Install unknown apps"
- Try again

For issues, see [DISTRIBUTION.md](https://github.com/msligar13-ship-it/porch-light-android/blob/main/DISTRIBUTION.md)
